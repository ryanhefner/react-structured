Describe your pages with Schema.org data and render it as JSON-LD. react-structured works in React applications, including Next.js, and uses schema-dts for exhaustive type coverage.

## Choose a component

| Component                                 | Use it for                                                      |
| ----------------------------------------- | --------------------------------------------------------------- |
| [Schema](/docs/schema)                    | One entity with a known Schema.org type                         |
| [Graph](/docs/graph)                      | Connected entities with stable identifiers                      |
| [JsonLd](/docs/json-ld)                   | A complete JSON-LD document you already own                     |
| [Rich-result helpers](/docs/rich-results) | Common article, product, breadcrumb, FAQ, and organization data |

## Get started

[Install the package](/docs/getting-started), then use the component that matches your content. Structured data complements titles and social metadata; it does not replace them or guarantee a rich result.
